# 🧠 Quiz App

A simple and interactive **Quiz App built with React.js**. Users can answer multiple-choice questions and test their knowledge through a clean and responsive interface.

## 🚀 Features

* Multiple-choice questions
* Interactive answer selection
* Displays the correct answer
* Tracks quiz progress
* Shows final score
* Restart quiz functionality
* Responsive design

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML
* CSS
* React Hooks (`useState`)

## ⚙️ Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Go into the project folder:

```bash
cd quiz-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal.

## 🎯 How It Works

1. The app displays a question with multiple options.
2. Select an answer.
3. The app checks whether the selected answer is correct.
4. Move to the next question.
5. After all questions are completed, your final score is displayed.
6. You can restart the quiz and try again.
